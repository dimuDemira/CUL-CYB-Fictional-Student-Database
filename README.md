# CUL-CYB 371 – Student Dataset

## Assignment Two
This project contains a fictional student dataset created with Python.

### Dataset fields
- Student ID
- Department
- Level
- Attendance Percentage
- Average Examination Score

### Files
- `student_dataset.py` – Python program that creates the dataset.
- `students.csv` – Generated dataset containing 12 fictional students.

### How to run
1. Install Python 3.
2. Open a terminal in this project folder.
3. Run:

```bash
python student_dataset.py
```

The program creates `students.csv` in the same folder.

**Note:** All student records are fictional and are provided for academic demonstration only.
